Website privacy

For cookiez.uk. Last updated: 25 September 2026.

This covers the website. For the browser extension, see the extension privacy policy.

This website doesn't use cookies, doesn't track you, and doesn't ask for any of your details.

What this website doesn't do

  • No cookies of any kind, so there's no cookie banner.
  • No analytics or visitor statistics.
  • No adverts, and no tracking pixels.
  • No fonts, scripts or images loaded from other companies' servers. Everything comes from this site.
  • No forms, accounts or sign-ups.

What this website saves on your device

One thing, and only if you use the light/dark button in the header: which theme you picked, saved as the word "light" or "dark" in your browser's local storage. It's there so the next page opens in the same theme. It isn't a cookie, it stays on your device, and it's never sent to us or anyone else.

If you switch back to the same theme as your system, it's removed. You can also clear it by clearing this site's data in your browser.

What the web host sees

When you visit any website, your browser sends the server your IP address, the page you asked for, and some details about your browser. That's how pages get delivered, and this site is no different.

This site is hosted on GitHub Pages. GitHub says that when a Pages site is visited, the visitor's IP address is logged and stored for security purposes. We can't see those logs and don't use them. You can read how GitHub handles this data in GitHub's privacy statement.

Links to other sites

This site links to GitHub, where the source code is published, and to the Chrome Web Store. Those sites have their own privacy policies, which apply once you follow a link.

Your rights

Under UK data protection law you can ask what personal data is held about you, and ask for it to be corrected or deleted. This site holds none itself, and the server logs are held by GitHub, as described above. If you have a concern, contact us using the details below. You can also complain to the Information Commissioner's Office at ico.org.uk.

Changes

If this policy changes, the new version will be posted here with a new date at the top.

Contact
